# Woko v0.6.6

Woko v0.6.6 adds opt-in Web Push notifications to the installed PWA. Users can receive work-order notifications on supported phones and browsers while the app is backgrounded or closed.

## Included

- An opt-in prompt in the authenticated PWA, with Indonesian and English status messages.
- A custom service worker that displays received notifications and opens the relevant work order when tapped.
- Device subscription registration, persisted per user and device.
- Background-job delivery for every newly created Woko notification.
- Automatic removal of expired or invalid push subscriptions.
- Existing in-app and email notification delivery remain unchanged.

## Upgrade

1. Deploy over HTTPS. Web Push is unavailable over plain HTTP (except localhost).
2. Run database migration `0018_web_push_notifications.sql`; the normal `npm run db:migrate` or Compose `migrate` service applies it automatically.
3. Generate one VAPID key pair and store it in the protected production environment:

   ```bash
   npx web-push generate-vapid-keys
   ```

4. Set the generated values without rotating them between deployments:

   ```dotenv
   WEB_PUSH_VAPID_PUBLIC_KEY=generated-public-key
   WEB_PUSH_VAPID_PRIVATE_KEY=generated-private-key
   WEB_PUSH_SUBJECT=mailto:notifications@example.org
   ```

5. Rebuild and deploy the web and API services. Users must open the installed PWA and select **Enable device notifications** once. iPhone users must install the PWA to the Home Screen before Safari can receive Web Push.

If VAPID keys are omitted, Woko continues to operate normally and shows that device notifications are not configured; no subscriptions or push deliveries are attempted.

## Validation

1. Use a supported, HTTPS-served installed PWA and sign in.
2. Enable device notifications and approve the browser permission prompt.
3. Create a work-order action that notifies a second account.
4. Confirm that the second device receives a system notification while Woko is closed or backgrounded.
5. Tap it and verify Woko opens the related work order.

```bash
npm run typecheck
npm test
npm run build
```
